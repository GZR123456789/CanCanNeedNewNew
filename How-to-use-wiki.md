# 📖 How to Use Our Wiki Site ✨
Welcome to Team 19's Wiki Help Page!

## 🔍 How to open the wiki?
1. Open your browser 🌐
2. Visit our link: https://GZR123456789.github.io/CanCanNeedNewNew/
3. Press Ctrl+Shift+R to refresh the page ✅

## 📝 How to edit content?
1. Go to our GitHub repository
2. Open index.md or other files
3. Click the edit button ✏️
4. Save and wait 1-2 minutes ⏳

## ⚠️ If the page is wrong?
- Use Ctrl+Shift+R to clear cache 🔄
- Wait for GitHub Pages deployment ✅
